## Technical Approach & Quality Standards

- **Semantic HTML5:** Proper use of structural elements (`header`, `main`, `section`, `nav`, `footer`) and logical heading hierarchies.
- **Modern CSS3:** CSS variables for design systems, Flexbox, and Grid for responsive layouts. No external frameworks like Tailwind or Bootstrap are used to demonstrate core competency.
- **Accessibility (a11y):** Keyboard navigation, `focus-visible` styling, sufficient color contrast, semantic form labels, and ARIA attributes where applicable (e.g., live regions for validation).
- **Responsive Design:** Mobile-first approach scaling up to 1440px desktop widths smoothly, ensuring no clipping or overflow.
- **Performance:** Zero external dependencies, utilizing system fonts or lightweight web fonts, and highly optimized asset delivery.

## Quality Assurance & Verification
All projects were independently developed and passed rigorous QA checks including:
- Mobile responsiveness on multiple viewports
- Keyboard-only navigation tests
- Functional testing of edge cases (especially in the Temperature Converter, e.g., Absolute Zero constraints)
- Visual alignment and contrast checks
