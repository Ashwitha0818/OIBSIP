# LuminaWorkspace - Landing Page

A premium, responsive landing page for an ergonomic desk brand. Built strictly with HTML5 and CSS3 without any JavaScript.

## Features & Implementation
- **Zero JavaScript:** Mobile navigation is implemented using an accessible CSS-only checkbox hack.
- **Responsive Layout:** CSS Grid and Flexbox ensure flawless display across 320px to 1440px widths.
- **Design System:** Custom CSS variables govern colors, spacing, and typography (Inter font).
- **Accessibility:** Semantic HTML tags (`<header>`, `<main>`, `<nav>`, `<footer>`), `focus-visible` styling, sufficient color contrast, and `prefers-reduced-motion` support.

## Project Structure
- `index.html`: The semantic structure of the landing page.
- `css/style.css`: All styling rules, including variables and media queries.
