# Ashwitha Gupta - Personal Portfolio

A professional, fast, and accessible personal portfolio for Ashwitha Gupta. Built strictly with HTML5 and CSS3.

## Features & Implementation
- **Semantic HTML5:** Clean document outline, logical heading structure, and appropriate landmarks.
- **Modern CSS3:** CSS variables for a consistent high-contrast design system. CSS Grid used for the skills and projects layout.
- **Accessibility:** 
  - Valid `focus-visible` states for keyboard navigation.
  - Proper contrast ratios (Slate 900 on White).
  - Semantic labels for social links (GitHub, LinkedIn).
- **Responsive Layout:** Smoothly adapts from 320px mobile viewports up to large desktop screens.
- **No JavaScript:** The entire portfolio, including the mobile navigation toggle, is achieved using CSS.

## Project Structure
- `index.html`: The structural markup.
- `css/style.css`: The stylesheet including custom properties, layout grids, and media queries.
